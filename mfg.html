101 World Cup HQ — how it all works

A plain-English tour of the public dashboard and the MFG cockpit. Skim it once, you'll be set.

1What this is

  • World Cup HQ is MFG's command centre for the 2026 FIFA World Cup (Jun 11 – Jul 19, Canada / Mexico / USA).
  • It's a real-time intelligence + production tool. You read the world from it. You also make the work happen from it.
  • Two surfaces, one system:
    • Public Dashboard — what the wider team sees. News, social chatter, fixtures, creative work.
    • MFG Cockpit (you're here right now) — where the MFG team produces and ships the content that powers the public dashboard.
  • Every surface is password-gated. The same password unlocks all three gates (dashboard, creative, MFG); each gate sets its own cookie so sessions stay separate.

2Public Dashboard — what's in it

  • Live tab — the headline surface:
    • Breaking ticker across the top — short, flag-led one-liners.
    • Pinned bookmarks bar — chips for any card the user has starred. Click to scroll + flash; × to unpin.
    • Sentiment heatmap — volume × sentiment per market. Flashes open once on first load.
    • Filter pills — All / Recent (72h) / Canada / Germany / UK / USA / Game / Culture. Multi-select with OR.
    • News carousel — tagged Canada / USA / Germany / UK / Macro / Global. Each card links out.
    • Social Trends carousel — tagged game / food / music / fashion / fandom / memes, with platform pills (X / TikTok / IG / Reddit / YouTube), volume 🔥 dots, and sentiment.
    • Entity auto-linking — coach / player / team / venue mentions are clickable; clicking drops them into search and filters every surface.
  • Fixtures tab — all 104 matches.
    • Three views: Calendar, By Date, Standings (live recompute from scores).
    • Filter by stage; "⏱ Next 24h" toggle for what's kicking off soon.
    • Today gets a TODAY badge + glowing left guide.
  • Creative tab — gated separately. Three sub-tabs: WC Engine, YT × Genius, Fox S2. Cards come from Supabase (live MFG uploads) merged with hardcoded assets. Sort + market filter pills. Drive videos play inline in an overlay.
  • Today's Reactive — red pill at top of Live. Opens a market chooser → goes to a per-market briefing page with two intelligence reads (Cultural + Match) and three iPhone-style storyboards.

3MFG Cockpit — what's in here

  • 🔄 Refresh Content — runs a Gemini-grounded sweep of WC2026 news / Reddit / social and inserts fresh rows into the public dashboard's Live feed. Watch the overlay's progress bar; rows appear immediately on index.html after publishing.
  • 🔥 Today's Reactive — paste a strategist's brief (or upload .txt / .md / .pdf / .docx), pick the market, hit Execute. Gemini converts the raw brief into the structured briefing the public Today's Reactive surface renders. Review the conversion, then Publish.
  • 📅 Content Calendar — per-market production calendar across Lead Up → Group Stage → Knockouts → Final. Social / Reactive / Digital OOH slots. Canada is live; USA / UK / Germany on the way.
  • 🧯 Global Triage — drag-and-drop kanban for work across markets. Auto-groups by tag (creative / strategy / macro / activation / media / production / talent / partnerships / legal). Soft-delete with a 5-second Undo toast. Snapshots saved to Supabase.
  • 🎬 Creative Uploads — post Drive-hosted creative to the public Creative tab. Multi-select markets, optional Bento slot, optional Live-from / Live-until window. Files stay on Drive — only the link is stored. Drive files must be "Anyone with link" or the iframe preview breaks.
  • 📋 Audit Log — chronological feed of every publish across Creative / Triage / Reactive. Filter chips + search; CSV export.

4Markets — how each gets and uses its own data

  • World Cup HQ runs five markets in parallel: 🇨🇦 Canada, 🇺🇸 USA, 🇬🇧 UK, 🇩🇪 Germany, and 🌍 Macro / Global (cross-market stories — FIFA news, pricing, broadcast, regulation).
  • Every piece of content is tagged with at least one market. The filter pills at the top of the Live tab flip the public dashboard to one or more markets at a time.
  • What each market sees on the public dashboard:
    • News & social — filtered by tag (Canada / USA / Germany / UK / Macro / Global). A Canada-tagged article only shows under "All" or under the 🇨🇦 pill.
    • Creative assets — tagged with one OR many markets (comma-separated). A multi-market asset surfaces under each market's filter pill, not just the first one.
    • Today's Reactive — its own per-market briefing page reached via the red "Today's Reactive" pill on Live. Different Cultural read, Match read, and three storyboards for each market.
    • Content Calendar — its own per-market production schedule (Social, Reactive, Digital OOH slots across Lead Up → Group Stage → Knockouts → Final).
    • Fixtures, Standings, Ticker — shared across all markets (the matches don't belong to any one market).
  • How each market gets fed:
    • Auto-refresh (5am NY cron) — one Gemini sweep covers all five markets at once. The prompt explicitly instructs Gemini to spread items across Canada / USA / Germany / UK / Macro / Global so no one market dominates.
    • Manual Refresh Content button — same Gemini flow, run on demand from the cockpit. Fills every market in a single run.
    • Today's Reactive (cockpit) — done one market at a time. Pick the market, paste or upload the strategist's brief, hit Execute, Gemini converts it, then Publish. The result only shows on that market's Today's Reactive page.
    • Creative Uploads (cockpit) — the uploader multi-selects markets per asset. One upload can serve several markets if the creative is global, and the same row appears under each market's pill.
    • Manual "refresh everything" in chat — when Claude is asked to refresh in chat, it sweeps web + Reddit and edits data.js directly with new items already tagged by market.
  • Today's status by market:
    • 🇨🇦 Canada — fully live. Today's Reactive briefing + Content Calendar both populated.
    • 🇺🇸 USA, 🇬🇧 UK, 🇩🇪 Germany — exist as filter pills, receive News / Social / Creative items, but Today's Reactive and Content Calendar are marked "Soon" until the team produces those briefings.
    • 🌍 Macro / Global — cross-market stories (FIFA pricing, ticketing controversy, broadcast deals, regulatory). No dedicated Reactive page; Macro items surface on every market's Live feed.

5How content flows

  • Automatic, daily — a Vercel cron hits /api/refresh at 5am New York every morning. Gemini runs 12+ live Google Search queries, structures the results, writes to Supabase live_updates. You wake up to a fresh dashboard.
  • Manual, on-demand — hit the 🔄 Refresh Content button any time. Same flow, but you watch it run live (queries, sources, publish progress).
  • Manual, curated — the owner can also ask Claude in chat to "refresh everything" — deeper Reddit + web sweep, edits data.js directly, pushes to main.
  • The "Refreshed Xm ago" chip on the public dashboard always reflects the freshest Supabase row — auto / manual button / manual chat all bump it.
  • During the tournament (Jun 11 – Jul 19) — match results, scores, and standings update from data.js; the refresh flow also patches match statuses where it sees fresh results.

6Supporting cast (always-on)

  • Gemini button — bottom-right on both pages. Brand-safe assistant, mode-aware (Dashboard vs MFG). Bullet answers, three prepopulated chips above the input. Hit G to open.
  • Countdown pill — floating, drag-to-reposition. Counts down days / hours / minutes to kickoff.
  • Global search (Cmd + K) — searches news / social / matches / assets. Press ? for the full keyboard shortcuts overlay (1 / 2 / 3 for tabs, G for Gemini, Esc to close).
  • Tab "what's new" badges — gold-red pills on tab labels show items added since your last visit to that tab.
  • Theme toggle — light / dark. Persists across sessions.

7Where the data lives

  • Supabase is the shared brain — live_updates (news / social / ticker), creative_assets (Drive links), mfg_triage + snapshots, today_reactive, audit / dashboard updates.
  • data.js is the codebase content fallback — fixtures, hardcoded ticker / news / social, hardcoded creative. Edited via PR / push; never edited live by the cockpit.
  • Vercel hosts the static pages + the API functions (gates, Gemini proxy, refresh, sb-write). No build step — push to main and it's live in seconds.
  • Gemini 2.5 Flash + Google Search grounding powers Refresh Content and the Today's Reactive converter. Output is grounded — sources are surfaced in the refresh overlay.

8Things to know (the small print)

  • Refreshes are additive — they never delete existing rows. The public dashboard caps how many show; older items just roll off the bottom.
  • Creative uploads survive deploys — they're in Supabase, not the codebase. Pushing new code never wipes them. Only the × button on a card deletes.
  • Drive sharing — every uploaded Drive asset must be set to "Anyone with the link can view" or thumbnails / inline playback break.
  • Multi-market assets — pick more than one market; the card surfaces under each market's filter pill.
  • The MFG gate cookie lasts 7 days. The Creative-view gate is 12 hours. The Dashboard gate is 8 hours (or 7 days with "remember me").
  • If something looks stale — check the "Refreshed Xm ago" chip on the public dashboard, then the Audit Log here. The two together tell you exactly what shipped and when.
